# Touchingz Food one-page website

Single-page website for Touchingz Food Pvt. Ltd (Pure • Clean • Crafted).

| Path | What it is |
|---|---|
| `index.html` | Current site |
| `preview/index.html` | Alternative version with the new **Our Kitchen** section (real photos of the production kitchen). Some image spots still use the original photos and are waiting for stock photos. |

Each page is a single self-contained HTML file with its images embedded, so it can be served as-is by any static host (GitHub Pages, Netlify, etc.).

The enquiry form posts to FormSubmit (`formsubmit.co`) and emails touchingzfoods@gmail.com. The first real submission sends a one-time activation email to that inbox, which has to be confirmed before messages arrive.
